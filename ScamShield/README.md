# ScamShield AI — Anti-Phishing & Fraud Sentinel

Полноценный локальный прототип (MVP) системы кибербезопасности для анализа подозрительных писем, счетов и ссылок на фишинг.

## Как запустить:
1. Откройте Терминал в этой папке.
2. Запустите сервер:
   ```bash
   python3 server.py
   ```
3. Откройте в браузере: `http://localhost:8080`

## Архитектура:
- **Core Engine (`server.py`):** Встроенный эвристический сканер признаков социальной инженерии, детекция IP-подделок, typosquatting брендов (HMRC, Barclays, Apple), анализ подозрительных TLD-зон и live DNS/SSL probing.
- **Web Interface:** Интерактивная панель в стиле Cyber Sentinel с расчетом индекса риска и выводом индикаторов компрометации (IoC).
